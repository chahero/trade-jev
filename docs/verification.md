# 검증 기록

2026-09-20 KST. 실제 Binance 공개 시세와 프로젝트의 Jev 인증으로 확인했습니다.

## 기능

- `pytest -q`: 15개 통과. 전액 매수 비용, 부분 비중, 잔고, MDD, 잘못된 가격,
  미래 봉 차단, 다음 봉 시가 체결, API 실패/호출 예산, 기준 전략 동일성,
  실시간 추론 후 시세 취득/봉당 한 번 판단, 시세 누락/중복, 입력/Origin 검증,
  재시작 시 실시간 정지, 다운로드의 관찰 범위와 응답 헤더 검사.
- `npm run build`: TypeScript 검사 및 Vite 프로덕션 빌드 통과.
- 실제 2025-01-01~2025-01-08 UTC 672봉 규칙 전략 완주. 39회 거래.
  결과는 연결/회계 검증용 한 구간이며 Jev 성과 결과가 아닙니다.
- 실제 Jev 호출 1회: 목표 BTC 0%, 951ms, 확률 0/25/50/75/100에
  0.31/0.18/0.28/0.07/0.16 반환. 호출 예산 1회로 저장했습니다.
- 실제 현재 시세 수신: 마감 봉 96개, 규칙 전략 실시간 모의계좌 1회 체결.
  검증 후 실시간 연결 중지. 실제 거래소 주문은 없음.
- IAB에서 데이터 불러오기 → 한 단계 → 자동 재생 → 일시정지 → 되감기 →
  저장 기록 한 단계 → 완료 실험 복원 → 실시간 생성/시작/중지 확인.
- Jev 저장 기록의 마지막 단계에서는 재생/한 단계 버튼이 비활성화되고,
  기록 재생이 새 API 호출로 넘어가지 않음을 확인.
- 브라우저 콘솔 오류 없음. 다운로드는 attachment 응답과 API 내용 검사로 확인.

## 시각 검증

기준: `design-concept.png`. 렌더: `desktop.png`, `mobile.png`.
Codex IAB의 뷰포트 API로 1536×1024와 390×844를 검사했습니다.
전체 화면 API의 캡처 오류는 같은 IAB의 CDP 명시적 clip 캡처로 해결했습니다.
캡처 도구의 스케일/여백은 렌더 측정값과 다를 수 있으며 DOM 치수로도 확인했습니다.
모바일 document scrollWidth 375px ≤ viewport 390px: 페이지 가로 넘침 없음.
view_image로 시안과 최신 데스크톱/모바일 캡처를 직접 확인했습니다.

| 항목 | 기준 / 확인 | 수정 또는 의도한 차이 |
|---|---|---|
| 화면 구조 | 상단 탭, 설정, 4개 지표, 차트/판단, 하단 비교/거래 | 동일 구조. 저장 실험 행을 추가해 높이 증가 |
| 색상 | 어두운 배경, 얇은 구분선, 라임 선택/매수, 코랄 매도 | 토큰 기반 적용, 그림자/장식 이미지 없음 |
| 글꼴 | 한국어 sans + 숫자 monospace | Noto Sans KR + IBM Plex Mono, 로컬 대체 글꼴 제공 |
| 차트 | 실시간 데이터와 가격/계좌 축 | 컨테이너 크기를 측정해 모바일 축 글자 축소 문제 수정 |
| 간격/패널 | 24px 안팎 외곽, 좁은 패널 간격, 작은 모서리 | 26px 외곽, 14px 간격, 5px 모서리 |
| 동작/상태 | 재생, 단계, 속도, 되감기, 확률 막대 | 기록 끝에서 추가 호출 차단. 규칙 전략에 가짜 확률 없음 |
| 짧은 기록 | 첫 단계 시간축 | 같은 시각이 5번 겹치던 라벨을 고유 인덱스로 수정 |
| 비교선 | 선택 전략 라임 | 규칙 비교선과 겹칠 때 선택 전략 색상을 우선 표시 |
| 문구 | 시안의 제목/탭/주요 액션 유지 | UTC, 종료일 미포함, 호출한도, 저장 실험, 실시간 폴링 안내 추가 |

시안의 핵심 시각 체계를 유지하며 실제 사용 흐름을 검증했습니다.
의도한 차이: 캔들 그림 대신 선 차트, 최근 최대 400봉 가격 뷰,
UTC 시간 통일, 실제 데이터를 사용한 값, 호출 예산/저장/오류 상태,
실시간 REST 폴링. 가상의 시안 수치와 모델 설명은 구현에 넣지 않았습니다.
